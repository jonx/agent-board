---
name: restructure
description: Restructure code or documents within a defined scope while preserving their externally observable behavior or meaning.
---
Identify the coupling or organization problem and the boundaries that must remain stable. Inspect consumers before moving or renaming interfaces. Work in small coherent changes; update references and use the relevant existing checks to verify preservation.

Coordinate overlapping file claims and use separate worktrees when agents edit concurrently. Return the changed structure, preserved contracts, verification and remaining risks. Do not expand a reorganization into a feature rewrite. Record a reusable lesson only when evidence supports it.
