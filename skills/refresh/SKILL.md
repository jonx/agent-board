name: refresh
description: Refresh a stale project brief or handoff against the current repository and verified work state.
---
Compare the existing brief with the current code, recent changes, open tasks and unresolved decisions. Verify commands and references before presenting them as current. Preserve useful conventions and distinguish facts, assumptions and pending work.

Publish a self-contained brief through board_context, with the goal, current state, how to continue and remaining uncertainties. Avoid dependency upgrades or unrelated rewrites unless requested. If the existing skill caused a stale or misleading handoff, record the concrete failure as feedback.
